# 팩: MCP 서버 (Model Context Protocol 서버를 만들 때)

> 선택형 팩 — 이 프로젝트에 해당 없으면 이 파일을 삭제한다.
> 출처: hanjadic 프로젝트 실측(2026-08).

## 프로토콜

- **stdio 서버의 stdout은 프로토콜 채널이다.** 로그를 stdout에 찍으면 JSON-RPC가 깨진다 —
  로그는 전부 stderr로. (일반화: 프로토콜 채널과 로그 채널을 섞지 않는다.)
- **연결 판정은 UI 표시가 아니라 실제 도구 호출로 한다.** 로컬 stdio 서버는 커넥터 목록에
  안 뜨는 것이 정상이고, 승인 프롬프트가 안 뜨기도 한다 — 미연결로 오해하기 쉽다.

## 클라이언트별 등록

- **Claude Code**: 프로젝트 스코프(`.mcp.json`)는 상대경로 + 프로젝트 cwd로 돈다.
- **Claude Desktop류**: 임의 cwd에서 띄우므로 **절대경로 + `cwd` + `env`가 전부 필요**하다.
  트레이 종료까지 설정을 다시 읽지 않는다(창 닫기로는 부족).
- **Windows에서는 `PYTHONIOENCODING=utf-8`이 없으면 서버 로그가 UnicodeEncodeError로 깨진다.**

## 테스트

- **함수 직접 호출로는 직렬화·도구 등록·핸드셰이크가 검증되지 않는다** — 하위 프로세스 +
  실제 클라이언트 왕복으로 테스트한다. 느리지만(10건에 17초) 정작 깨지는 곳이 그 계층이다.

## Python 일반 함정 (편승 수록)

- **`sqlite3.Connection`의 `with`는 트랜잭션만 관리하고 커넥션을 닫지 않는다** — close를
  보장하는 래퍼를 따로 만든다.
